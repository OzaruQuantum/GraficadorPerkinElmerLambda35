# GraficadorPerkinElmerLambda35

Aplicación de escritorio para visualizar y analizar archivos de espectrofotometría `.sp` generados por el equipo Perkin Elmer Lambda 35.

## Características

- Carga múltiples archivos `.sp` simultáneamente.
- Visualización superpuesta de espectros.
- Personalización de colores, títulos y ejes.
- Control interactivo de rangos (zoom manual y automático).
- Exportación de gráficas a PNG, PDF, SVG, JPG, TIFF.
- Exportación de datos a CSV.

## Requisitos

- Python 3.7 o superior.
- Dependencias: `numpy`, `matplotlib` (vienen incluidas en `requirements.txt`).
